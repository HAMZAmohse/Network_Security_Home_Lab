# Detailed Roadmap

## Phase 1 — Foundations
- Confirm virtualization platform
- Review available CPU/RAM/storage
- Define IP/VLAN plan
- Define virtual topology

## Phase 2 — Virtual Network
- Create required virtual networks
- Verify isolation and connectivity

## Phase 3 — pfSense
- Install pfSense
- Configure WAN/LAN
- Configure DHCP/DNS as needed
- Create firewall rules
- Test and document behavior

## Phase 4 — VLANs
- Configure VLAN 10 Internal LAN
- Configure VLAN 20 Servers
- Test permitted and blocked traffic

## Phase 5 — Hosts
- Deploy Windows Client
- Deploy Ubuntu Server
- Configure basic administration and networking

## Phase 6 — Analysis
- Capture traffic with Wireshark
- Identify DNS, TCP, HTTP/HTTPS and other relevant traffic

## Phase 7 — Detection
- Deploy Suricata
- Generate safe test activity
- Verify alerts and explain them

## Phase 8 — SIEM
- Deploy Wazuh
- Collect logs/events
- Investigate relevant detections

## Phase 9 — Scenarios
- Build safe defensive scenarios
- Collect evidence
- Investigate
- Document findings and response

## Phase 10 — Portfolio
- Final network diagram
- Architecture explanation
- Screenshots
- Detection examples
- Lessons learned
- Final README
- LinkedIn presentation
