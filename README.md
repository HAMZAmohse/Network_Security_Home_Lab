# Network Security Home Lab

## Status
Not started yet. The roadmap and initial topology are planned only.

## Goal
Build a practical, documented network-security home lab that demonstrates networking, segmentation, firewalling, traffic analysis, IDS/IPS, SIEM, and basic defensive investigation.

## Planned stack
- pfSense
- Windows Client
- Ubuntu Server
- Wireshark
- Suricata IDS/IPS
- Wazuh SIEM

## Roadmap
1. Define topology and virtualization plan
2. Build the virtual network
3. Install and configure pfSense
4. Create VLAN 10 Internal LAN and VLAN 20 Servers
5. Add Windows Client and Ubuntu Server
6. Build and test firewall rules
7. Analyze traffic with Wireshark
8. Deploy and test Suricata
9. Deploy and test Wazuh
10. Create safe detection/investigation scenarios
11. Document architecture, tests, findings, and lessons learned
12. Publish a polished portfolio version

## Project rule
Do not mark a phase complete until it is implemented, tested, and documented.

## Security rule
Never store passwords, API keys, private keys, tokens, or other secrets in this project folder or public repositories.
